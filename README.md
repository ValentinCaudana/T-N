# 🎟️ Tickets Notify

Tickets Notify is a web application to track football matches and notify users about ticket availability.

## 🚀 Features (WIP)
- Browse upcoming football matches
- Filter matches by date and region
- User authentication (planned)
- Reserve and manage tickets (planned)

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (coming soon)
- Node.js / Express (backend – planned)

## 📌 Status
This project is currently under active development.
Frontend structure and UI are in progress.
